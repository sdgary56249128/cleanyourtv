# Personal Chromecast space wallpapers

This fork-only preset keeps the four-app dock and YouTube-to-SmartTube mapping, and rotates ten generated science-fiction landscapes every 30 minutes. Images are 1920×1080 JPEGs under 300 KB. `wallpaper_true_color` keeps dark sky gradients smooth on the Chromecast 4K with 2 GB RAM.

Apply from the repository root after setting `TV_ADB_BINARY` and `TV_HOST` to the paired connection:

```bash
tools/theme.sh personal/chromecast-space
```

The wallpapers were generated with the built-in ImageGen tool (not an API/CLI workflow), then exported to JPEG. They are imaginative artwork, not astronomical photography. No third-party image service is required.

## Home and remote settings

The dock uses 70% opacity, with 15% wallpaper dimming. After two idle minutes on Home, a drifting clock appears over the space wallpaper, dimmed by 40%. The system Clock screensaver uses the same wallpaper settings. App grids and order are unchanged.

Open the Home gear → Remote buttons to choose an installed TV app for each short or long press. YouTube defaults to SmartTube on a tap and 動畫瘋 on a hold; Netflix defaults to Netflix on a tap and MX Player on a hold. Theme default restores these mappings. Choices persist across theme changes and apply to running key helpers immediately. Volume and voice buttons are unchanged. Physical remote presses still need verification on each firmware.

## Version 3.4 upgrade

This fork merges upstream v3.4.0 while keeping the space theme and remote app pickers. Chinese button labels are translated; other locales use the default English labels through Android resource fallback, avoiding duplicate English resource entries. `manage.py set` protects the tracked personal preset, and the config-folder test counts tracked files rather than local work or backups.

## On-TV scene controls

Home gear → Launcher settings offers idle-clock timeout, wallpaper rotation interval and order, and Home wallpaper brightness. Each picker can follow the theme again. A new interval resumes the wallpaper collection after a fixed-picture choice. Settings apply on returning Home, persist across app upgrades, and reset with Follow theme or a theme push.
